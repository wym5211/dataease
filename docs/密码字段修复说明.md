# 用户密码字段修复说明

## 修复内容

### 问题
用户创建时填写的自定义密码没有传递到后端，始终使用默认密码 `DataEase@123456`

### 修复文件

#### 1. 后端DTO修改
**文件**: `sdk/api/api-permissions/src/main/java/io/dataease/api/permissions/user/dto/UserCreator.java`

**修改**: 添加password字段
```java
@Schema(description = "密码")
private String password;
```

#### 2. 后端Service修改
**文件**: `core/core-backend/src/main/java/io/dataease/core/permissions/user/CoreUserServer.java`

**修改**: 使用传入的密码或默认密码
```java
// 使用传入的密码或默认密码
String pwd = StringUtils.isNotBlank(creator.getPassword()) ? creator.getPassword() : "DataEase@123456";
user.setPassword(passwordEncoder.encode(pwd));
```

#### 3. 前端API适配器修改 ⭐ 主要修复
**文件**: `core/core-frontend/src/views/permissions/user/api/adapter.ts`

**修改**: 在requestBody中添加password字段
```typescript
const requestBody = {
  account: data.username,
  name: data.nickName,
  email: data.email,
  phone: data.phone,
  password: data.password,  // 新增：传递密码字段
  roleIds: data.roleIds ? data.roleIds.map(id => parseInt(id)) : [],
  enable: data.status === 1
}
```

## 技术细节

### 密码处理流程
1. **前端**: 用户在表单中输入密码 → `UserDialog.vue` formData.password
2. **API适配器**: `adapter.ts` 将 `data.password` 映射到 `requestBody.password`
3. **后端接收**: `UserCreator` DTO 接收password字段
4. **密码加密**: `CoreUserServer` 使用 BCryptPasswordEncoder 加密
5. **数据库存储**: 加密后的密码存储到 `sys_user.password` (BCrypt格式: $2a$...)

### BCrypt验证流程
```java
// CoreLoginServer.java 中的验证逻辑
if (user.getPassword().startsWith("$2a$") || user.getPassword().startsWith("$2b$")) {
    matches = passwordEncoder.matches(pwd, user.getPassword());
}
```
