# DataEase 权限自动化测试设计方案

## 概述

使用 Playwright MCP 工具实现 DataEase 权限功能的端到端自动化测试，覆盖从登录到菜单访问再到数据资源操作的完整权限链路。

## 测试目标

- 验证多角色（admin + 普通用户）的权限隔离
- 测试菜单权限、数据访问权限、编辑操作权限
- 生成可重复执行的自动化测试脚本
- 失败时继续执行，最后汇总报告

## 测试架构

```
tests/e2e/permission/
├── config.ts              # 测试配置（URL、用户凭证）
├── login.spec.ts          # 登录流程测试
├── menu.spec.ts           # 菜单权限测试
├── dashboard.spec.ts      # 仪表板访问+编辑测试
├── screen.spec.ts         # 大屏访问+编辑测试
├── dataset.spec.ts        # 数据集访问+编辑测试
├── datasource.spec.ts     # 数据源访问+编辑测试
├── report.ts              # 结果汇总报告
└── run-all.ts             # 一键执行入口
```

## 执行流程

```
┌─────────────────────────────────────────────────────┐
│                    run-all.ts                       │
├─────────────────────────────────────────────────────┤
│  1. 检查服务状态（前端 8090 / 后端 8100）           │
│  2. 按顺序执行测试用例                              │
│     ├─ login.spec.ts (必须先通过)                   │
│     ├─ menu.spec.ts                                 │
│     ├─ dashboard.spec.ts (访问+编辑)                │
│     ├─ screen.spec.ts (访问+编辑)                   │
│     ├─ dataset.spec.ts (访问+编辑)                  │
│     └─ datasource.spec.ts (访问+编辑)               │
│  3. 收集结果，生成报告                              │
│  4. 输出汇总到控制台 + 保存 HTML 报告               │
└─────────────────────────────────────────────────────┘
```

## 前置条件

1. **服务运行**：前端 `localhost:8090`，后端 `localhost:8100`
2. **测试数据**：
   - admin 账号存在
   - 至少一个普通用户账号
   - 每类资源至少有2个测试数据（仪表板、大屏、数据集、数据源）
3. **权限配置**：普通用户对部分资源有只读权限，部分有编辑权限

## 技术实现

```typescript
// config.ts
```
