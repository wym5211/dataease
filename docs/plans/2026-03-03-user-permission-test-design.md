# 用户权限管理功能测试设计方案

日期: 2026-03-03

## 1. 测试目标

使用 Playwright MCP 自动化测试 DataEase 用户权限管理完整流程，验证以下功能：
- 用户登录
- 用户列表查看
- 创建新用户
- 分配角色
- 权限验证

## 2. 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                     测试执行流程                              │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 启动后端 (Standalone 模式)                          │
│  - 端口: 8100                                               │
│  - 数据库: MySQL (dataease10)                               │
│  - 监控日志输出，检测 "Started CoreApplication"              │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 启动前端 (开发服务器)                                │
│  - 端口: 8081                                               │
│  - 监控日志输出，检测 "Local: http://localhost:8081"         │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 3: Playwright MCP 浏览器测试                           │
│  - 打开 http://localhost:8081                                │
│  - 执行登录 → 用户管理 → 创建用户 → 分配角色 → 验证流程       │
└─────────────────────────────────────────────────────────────┘
```

## 3. 测试场景

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问登录页 http://localhost:8081 | 显示登录表单 |
| 2 | 输入 admin / 123456 | 登录成功，跳转到首页 |
| 3 | 导航到权限管理 → 用户管理 | 显示用户列表页面 |
| 4 | 点击"新建用户" | 弹出创建用户对话框 |
| 5 | 填写用户信息（用户名、姓名、邮箱等） | 表单可正常填写 |
| 6 | 选择角色 | 下拉显示可用角色 |
| 7 | 保存用户 | 用户创建成功，列表刷新 |
| 8 | 验证新用户出现在列表中 | 新用户可见 |
| 9 | 测试完成，清理（可选） | 删除测试用户 |

## 4. 技术选型

- **进程管理**: Bash MCP（启动/监控后端和前端进程）
- **浏览器自动化**: Playwright MCP（导航、交互、断言）
- **测试框架**: 使用 Playwright MCP 的原生操作

## 5. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 后端启动失败 | 捕获错误日志，终止测试，报告问题 |
| 前端启动失败 | 捕获错误日志，终止测试，报告问题 |
| 登录失败 | 截图保存，记录错误信息 |
| 页面元素找不到 | 等待重试，超时后截图报告 |

## 6. 默认凭证

- 用户名: `admin`
- 密码: `123456`

（注：根据 application-standalone.yml 配置）
