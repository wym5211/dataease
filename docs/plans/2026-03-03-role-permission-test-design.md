# 用户角色权限测试设计方案

日期: 2026-03-03

## 1. 测试目标

验证 DataEase 的 RBAC（基于角色的访问控制）权限体系，确保：
- 角色权限配置正确生效
- 不同角色的用户只能访问授权的菜单
- 无权限的用户无法访问受限功能

## 3. 测试场景

| 测试用户 | 角色 | 预期可访问 | 预期不可访问 |
|----------|------|-----------|-------------|
| user_admin | 管理员 | 工作台、仪表板、数据大屏、数据准备 | 无 |
| user_normal | 普通用户 | 工作台、仪表板 | 数据大屏、数据准备 |
| user_limited | 受限用户 | 工作台 | 仪表板、数据大屏、数据准备 |

## 4. 技术方案

- **服务启动**: Bash MCP 启动后端(8100)和前端(8080)
- **浏览器自动化**: Playwright MCP
- **角色配置**: 通过菜单权限页面分配
- **验证方式**: 检查菜单是否存在/可点击，页面是否能访问

## 5. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 角色创建失败 | 记录错误，跳过相关测试 |
| 用户创建失败 | 记录错误，跳过相关测试 |
| 登录失败 | 截图保存，记录错误信息 |
| 权限验证失败 | 截图保存，记录实际 vs 预期 |

## 6. 测试菜单列表

- 工作台 (workbranch)
- 仪表板 (dashboard)
- 数据大屏 (data-visualization)
- 数据准备 (data-preparation)
