## 🔧 技术细节

### 密码处理流程
1. **前端**: 用户在表单输入密码 → `UserDialog.vue` → `formData.password`
2. **API适配器**: `adapter.ts` → `requestBody.password`
3. **DTO**: `UserCreator.password`
4. **Service**: `CoreUserServer` 使用 `BCryptPasswordEncoder` 加密
5. **数据库**: `sys_user.password` 存储 BCrypt 格式 (`$2a$10$...`)

### BCrypt 验证流程（CoreLoginServer）
```java
// Line 60-69 in CoreLoginServer.java
if (user.getPassword().startsWith("$2a$") || user.getPassword().startsWith("$2b$")) {
    matches = passwordEncoder.matches(pwd, user.getPassword());
} else {
    // 明文密码比较（首次登录时自动升级为BCrypt）
    if (pwd.equals(user.getPassword())) {
        matches = true;
        user.setPassword(passwordEncoder.encode(pwd));
        sysUserMapper.updateById(user);
    }
}
```
