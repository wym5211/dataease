# DataEase 视觉大胆提升计划

## 当前诊断

| 问题 | 表现 |
|------|------|
| **平淡无奇** | 所有页面看起来像同一个模板，缺乏辨识度 |
| **层次扁平** | 字号差距小（12/14/16/20），视觉重量几乎相同 |
| **品牌色弱** | 蓝色只用在按钮和选中态，品牌存在感低 |
| **空间单调** | 间距均匀但没有节奏感，缺少"呼吸" |
| **零动效** | 没有任何过渡动画，状态切换生硬 |
| **登录页普通** | 标准双栏布局，没有品牌记忆点 |

## 提升策略

### 方向：专业精致，自信大胆
不是花哨的渐变和特效，而是通过**排版力度、品牌色运用、空间节奏和微动效**建立高级感。

### 四个焦点

---

### 1. 登录页 — 品牌第一印象

- [x] 预热背景改为品牌深蓝 `#050e21`
- [x] 页面入场淡入动画（`loginFadeIn` 0.6s）
- [x] 左侧图片增加品牌渐变叠加层（`::after` pseudo-element）
- [x] 登录卡片圆角 4px→12px，阴影加深（0.12 透明度），hover 阴影增强
- [x] 边框淡化（`rgba(31,35,41,0.06)`），让卡片"悬浮"
- [x] 输入框高度 40→44px，圆角 8px
- [x] 登录按钮高度 44px，圆角 8px，字号 15px，过渡动效
- [x] 表单标题字号 20→22px
- [x] 品牌分隔线加粗 2→3px

**涉及文件**：`views/login/index.vue`

---

### 2. 仪表板编辑器 — 专业工具质感

- [x] 工具栏分隔线对比度提升（`#ffffff4d` → `rgba(255,255,255,0.15)`）

- [x] 选中态增加品牌色左边框指示器（`border-left: 2px solid var(--ed-color-primary)`）

**涉及文件**：`DbToolbar.vue`, `DvToolbar.vue`, `RealTimeTab.vue`, `RealTimeListTree.vue`

### 3. 数据源/数据集管理 — 层次分明

- [x] 树面板标题增加品牌色左侧竖线标记（`::before` pseudo-element）

**涉及文件**：`datasource/index.vue`, `dataset/index.vue`

---

### 4. 系统设置/权限管理 — 精致管理感

- [x] 面板头部底边线改为品牌色（`2px solid var(--ed-color-primary)`）

## 审查总结

### 修改统计
- **修改文件数**: 10 个
- **纯视觉改动**: 0 个功能性变更
- **新增 CSS**: 入场动画、渐变叠加层、左边框指示器、标题竖线标记

### 关键视觉变化

1. **登录页**: 从"标准企业表单"升级为"有品牌记忆点的入口"，卡片悬浮感 + 入场动画 + 图片叠加层
2. **编辑器**: 分隔线更清晰、组件列表过渡更平滑、选中态有明确的品牌色指示器
3. **数据管理**: 树面板标题增加品牌色竖线标记，建立视觉锚点
4. **权限管理**: 面板头部品牌色底边线，增强区域归属感

### 设计原则遵守
- 没有添加渐变文字或霓虹色
- 没有 glassmorphism
- 没有改变任何布局结构
- 没有影响任何功能交互
- 所有改动都是纯 CSS 视觉增强
